# Android版テスター募集ページ

HTMLとCSSだけで動く静的ページです。ビルドやライブラリのインストールは必要ありません。

## ファイル構成

```text
tester-page/
├── index.html                       ページの文章とリンク
├── css/style.css                    色・文字サイズ・レイアウト
├── assets/images/
│   ├── ailis-map-icon.png            アプリアイコン
│   └── ailis-map-overview.png        アプリ紹介画像
└── README.md                        この説明書
```

## ローカルで見る

`index.html`をダブルクリックしてブラウザで開いてください。スマートフォン表示を確認する場合は、ブラウザの開発者ツール（通常F12）のデバイス表示を使い、画面幅を390pxなどに設定してください。

公開するときは、このフォルダの中身を同じ構成のまま静的サイト用のサーバーへ配置します。

## GoogleフォームURLを変更する

`index.html`をテキストエディターで開き、`https://forms.gle/Yy2Ac9P2TXaCXn9T9`を検索してください。ページ上部と下部の2か所にある`href="..."`のURLを両方変更して保存します。変更箇所の直前にコメントもあります。

## プライバシーポリシーURLを変更する

`index.html`末尾の`https://silver174392.studio.site/privacy`を変更します。

## 文章を変更する

`index.html`の各見出しや本文の、HTMLタグに挟まれた日本語を書き換えて保存してください。例えば`<h2>参加に必要なもの</h2>`なら、「参加に必要なもの」の部分を変更します。タグや`href`などはそのまま残してください。

## 画像を変更する

`assets/images/`の画像を同じファイル名で置き換えます。画像の内容や縦横サイズが変わった場合は、`index.html`の該当画像の`alt`（画像の説明）と`width`・`height`も更新してください。紹介画像は切り取らず全体を表示します。

変更後はブラウザを再読み込みしてください。
